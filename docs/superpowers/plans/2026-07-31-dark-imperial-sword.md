# Dark Imperial Sword Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a 1% server-authoritative dean drop that equips as a 65-attack dark Imperial Sword with a visible dark blade aura.

**Architecture:** `src/rules.mjs` owns the item catalog, exact drop threshold, save sanitation, equipment authorization, and combat number. `src/http.mjs` supplies the server random value only for dean clear. `public/rules.js`, `public/ui.js`, and `public/game.js` mirror the valid weapon state, inventory presentation, and Canvas aura.

**Tech Stack:** Node.js ESM, SQLite persistence, native Canvas, Node test runner.

## Global Constraints

- Drop condition is exactly `darkSwordRoll < 0.01` and is generated by the server.
- Black Dark Imperial Sword attack is exactly `65`; lifesteal is the tier-three value of `30`.
- The sword is not purchasable or forgeable.
- Only `imperial_sword` and `dark_imperial_sword` may occupy the weapon slot.
